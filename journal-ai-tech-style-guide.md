# Journal AI/Tech — Style Guide (Noto Serif) + Light/Dark

## Typo (font)
- **Font principal (texte / articles)** : **Noto Serif**
- **Fallbacks** : `ui-serif, Georgia, Times New Roman, serif`
- **Code / snippets** : `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, "Liberation Mono", "Courier New", monospace`

### Paramètres de lecture (recommandés)
- Taille texte : **18–20 px** desktop (16–18 px mobile)
- Interligne : **1.6–1.75**
- Longueur de ligne : **62–72ch**
- Structure : une seule colonne, beaucoup d’espace blanc, séparateurs fins


---

## Accent (orange) + beiges (référence de l’image)
- **Orange accent (UI / icônes / boutons / highlights)** : **#F93C20**
- **Crème exact (du visuel, très “papier”)** : **#FEFEF3**
- **Beige de fond “journal / Claude-ish”** : **#F4F3EE**

### Règle d’usage (important)
- Utilise **#F93C20** pour l’accent (UI), mais **évite-le pour le texte de lien** sur fond beige clair (contraste parfois trop faible).
- Pour les **liens en texte**, utilise un orange **plus foncé** (même famille) :
  - **Link (texte)** : **#C73019**
  - **Hover** : **#AE2A16**


---

# LIGHT MODE (Journal sobre)

## Palette
- Background : **#F4F3EE**
- Surface (zones, encadrés, code blocks) : **#FEFEF3**
- Texte principal : **#141414**
- Texte secondaire : **#5A5A5A**
- Bordures / règles : **#D9D4C8**
- Accent UI : **#F93C20**
- Liens (texte) : **#C73019**
- Hover liens : **#AE2A16**

## Usage rapide
- Accent UI : boutons, puces, petites barres, icônes, surlignages courts.
- Liens : **#C73019** + soulignement (look “journal”).
- Séparateurs : lignes fines (bordures), pas de cartes lourdes, pas d’ombres.


---

# DARK MODE (Night journal)

## Objectif
Même sobriété, mais lisible sans “baver” (les sérifs peuvent devenir mous si le contraste est mal géré).

## Palette (proposée)
- Background : **#0F1115**
- Surface : **#151821**
- Texte principal : **#E8E8E8**
- Texte secondaire : **#B9B9B9**
- Bordures / règles : **#2A2F3A**
- Accent UI : **#F93C20**
- Liens (texte) : **#FF6A52**  *(plus clair pour contraster sur fond sombre)*
- Hover liens : **#FF826E**

## Usage rapide
- En dark mode, **#F93C20** peut fonctionner aussi pour les liens, mais le couple
  **#FF6A52 / #FF826E** donne souvent une lecture plus confortable en paragraphes longs.
- Garde les surfaces légèrement plus claires que le fond (effet “papier noir” discret).
